# AI 造型师：高转化模特图

用于将服装商品、目标人群、平台、风格、场景、模特类型和转化目标，整理成适合图片大模型使用的高转化模特图创作方案与英文 Prompt。

## 触发场景

- 用户需要“高转化模特图”“AI 造型师”“商品图转模特图”“服装上身图”。
- 用户需要淘宝、抖音、小红书、独立站、Instagram 等平台的服装主图或投放图。
- 用户提供服装商品图、平铺图、挂拍图、白底图，希望生成模特穿着效果。
- 用户需要突出显瘦、显高、高级感、通勤感、度假感、辣妹感、轻奢感等转化卖点。

不要用于设计师概念图、纯艺术海报、非服装商品图或直接复制品牌/名人/IP 肖像。

## 工作流

1. 读取 `style_config.json`，获得默认平台、画幅、模特类型、场景、姿势、光线、转化重点和避免项。
2. 解析用户需求，提取服装品类、颜色、材质、版型、目标人群、平台、场景、模特、风格和参考图信息。
3. 如果有商品参考图，强调保留服装颜色、版型、面料、结构和关键细节，不编造 Logo 或图案。
4. 做安全与版权检查；涉及真人肖像、品牌素材、Logo、名人或用户未授权参考图时，读取 `references/safety-and-rights.md`。
5. 生成中文造型方案，说明模特、姿势、场景、构图和转化重点。
6. 使用 `prompt_template.md` 或 `scripts/prompt_builder.py` 组合最终英文图片 Prompt。
7. 输出 `styling_plan`、`composition_plan`、`positive_prompt`、`negative_prompt` 和 `warnings`。

## 输出原则

- 服装必须是主角，版型、长度、领口、袖口、腰线、下摆和面料质感要清楚。
- 模特姿势自然，能帮助用户理解上身效果，不遮挡核心卖点。
- 场景服务商品，不抢画面主体。
- 主图/投流图要更直接，Lookbook 和品牌图可以更有氛围。
- 避免过度修饰导致商品失真，图片应保持可信、可购买、可转化。
- 英文 Prompt 使用可见画面描述，不堆空泛营销词。

## 文件使用

- `style_config.json`：产品后端或 Agent 读取的默认配置。
- `prompt_template.md`：人工或 Agent 拼接图片 Prompt 时的模板。
- `scripts/prompt_builder.py`：需要自动拼接、批量生成或默认值处理时使用。
- `references/safety-and-rights.md`：涉及真人、品牌、IP、参考图授权或肖像风险时读取。

## API 边界

当前 Skill 不直接调用图片生成 API，只输出创作方案、Prompt 和风险提示。后续接入具体图片模型时，应在 `scripts/` 下新增独立客户端文件，并从环境变量读取 API Key，不要把密钥写进 Skill 文档或配置。
